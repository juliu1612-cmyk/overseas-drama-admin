新增合集组 · 功能交互逻辑
  • 「+ 新增合集组」打开独立页面（顶部标签页），不再使用弹窗；列表操作列「编辑」同样跳转该页面并回填数据。
  • 合集组ID：新增时只读展示「保存后自动生成」，编辑时展示现有ID。
  • 合作范围（APP / YT / TT）：勾选标签后在其正下方展开对应授权信息填写区（上下相邻），取消勾选清空并隐藏。
  • 每个范围的到期时间可勾选「永久」，勾选后日期输入框禁用、保存值为「永久」。
  • 必填校验：名称（唯一）、性别标签、供应商、合作模式、本土/译制、已勾选范围的授权时间 / 到期时间 / 采买成本。
  • 剧本成本 / 出资金额 / IP成本单位为美元，保存后回列表展示并可导出。
  • 分成设置：按分成时间范围分组（分组内不再设置合作模式，合作模式为表单基础字段）；每个分组一组时间范围（精确到月；结束时间不能早于当前月份，可勾选「永久」：勾选后结束月输入框禁用、保存值为「永久」，永久段之后不可再有其他时间段），不同分组之间时间段不可重叠。
  • 每个分组下可添加多个分成模式（同一分组内分成模式不可重复：已被其他行选用的模式下拉置灰禁选，保存时二次校验），可选 利润/流水/流水阶梯分成/消耗/不分成；「不分成」与「流水阶梯分成」不设分成比例、只勾选分成范围（至少一个），消耗的分成范围不含社媒，其余分成模式单独设置分成比例（0~100）与分成范围。
  • 同一分组内不同分成模式的分成范围不能重复勾选：已被其他分成模式勾选的范围在页面上即时置灰禁选，保存时二次校验；采买-消耗的分成范围不含社媒。
  • 「确定」保存成功后自动返回列表并提示；「取消 / 返回列表」不保存直接返回。
